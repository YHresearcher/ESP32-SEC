# ESP32-SEC Web Installer

The site is hosted on GitHub Pages at https://yhresearcher.github.io/ESP32-SEC/.

## Experimental alpha opt-in
The release workflow builds firmware and **publishes timestamped ESP32-S3 binaries plus a Web Tools-compatible manifest** into the GitHub Pages artifact. The firmware and manifest share the same origin (no GitHub release binary CORS redirects).

A user must explicitly confirm their hardware and Chibi backup using a checkbox before the `esp-web-install-button` is shown.

- Target: ESP32-S3 N16R8, ST7789V 240x320, XPT2046. Not an original ESP32-DIV board.
- Local time filename suffix: `DD-MM-YYYY_HH-mm` in `Asia/Ho_Chi_Minh`.
- Flash offsets are parsed from `flasher_args.json` generated by ESP-IDF, not guessed.
- This is an **unverified experimental alpha**, not a stable release.
- Chrome/Edge desktop with Web Serial recommended. Always back up the original Chibi firmware/NVS.
- The source tree intentionally omits `web/manifest.json` and `web/firmware/*.bin`: both are generated automatically during release.
- `.github/workflows/release-alpha.yml` is the **only Pages publishing workflow**. `pages.yml` performs source validation.

The Serial Console requests permission through a user gesture.
