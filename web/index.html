ESP32-SEC

Bruce firmware for the Chibi ESP32-S3

A full-featured offensive-security firmware fork, built for ESP32-S3-WROOM-1-N16R8 with an ST7789V 240x320 screen and XPT2046 touch.

Authorized testing only. Use this firmware only on systems you own or are explicitly permitted to test.

No web installer is published yet. Build and flash locally:

git clone --recurse-submodules <repo-url>
pio run -e esp32-sec-chibi
pio run -e esp32-sec-chibi -t upload

Before flashing, back up existing firmware/NVS and confirm ROM bootloader recovery. On first boot, run Config > Calibrate Touch.
